## 🎯 1. 플랫폼 개발 목적 및 핵심 비전 (Purpose & Vision)

본 플랫폼은 언어의 장벽을 허물고 전 세계 학습자에게 맞춤형 언어 및 비판적 사고 훈련을 제공하기 위해 **3대 핵심 교육 목적**을 바탕으로 설계되었습니다.

1. **🌏 글로벌 ESL 영어 학습 지원 (English for ESL Learners)**:
   - 비영어권(ESL) 국가에서 영어를 공부하고자 하는 전 세계 학습자들에게 유튜브 고품질 미디어 기반의 직관적 청취, 섀도잉, 받아쓰기 훈련 환경 제공.
2. **🇰🇷 외국인을 위한 TOPIK 시험 통과 & 실전 한국어 교육 (Korean for TOPIK & KSL)**:
   - 유학, 취업, 이주 등으로 한국에 오고자 하는 외국인들이 **TOPIK(한국어능력시험)을 완벽히 통과**하고 실전 한국어를 익힐 수 있도록 전래동화, 표준 한국어, 문법 분석 환경 제공.
3. **🏹 한국인을 위한 직관적 원어민 어순/뉘앙스 교육 (English for Koreans)**:
   - 한국어 화자가 영어를 배울 때 겪는 번역의 한계를 극복하도록 이미지 직독직해(애로우 잉글리시), 원어민 뉘앙스(라이브 아카데미, 구슬쌤) 채널을 체계적으로 큐레이션하여 지원.

## 🎬 4. 좌우 2분할(Side-by-Side) 스튜디오 뷰 & 실시간 센터 자동 스크롤

기존 상하 배치로 인해 스크립트가 화면 아래로 밀려 잘리던 현상을 완벽히 해결하고, 데스크톱/태블릿 화면에 최적화된 **좌우 2분할 뷰**를 구축하였습니다.

```text
┌───────────────────────────────────────────────────────────────────────────────────────────┐
│  외우지 않고 🔥 영어를 길게 말하게 되는 이미지 영어회화훈련                        과제제출 ✓  │
│  [🎬 비디오 시청]  [🧠 IB 탐구]  [🎧 받아쓰기]  [🧩 빈칸]  [🎙️ 섀도잉]  [📊 슬라이드] ...     │
├─────────────────────────────────────────┬─────────────────────────────────────────────────┤
│  🎬 좌측: 고화질 영상 & 비주얼 플레이어    │  📜 우측: 실시간 대본 & 자막 타임라인 (총 112문장) │
│                                         │  [ 🔍 대본 문장 검색...                       ] │
│   ┌─────────────────────────────────┐   │  [ 📖 궁금한 단어 사전 바로 검색...    ] [🔍사전]│
│   │                                 │   │  ┌───────────────────────────────────────────┐  │
│   │   [ 유튜브 / 비디오 재생 화면 ]   │   │  │ 10. 나와 저녁을 보낼 시간이 있다고   33s │  │
│   │                                 │   │  │                                           │  │
│   │                                 │   │  │▶ 11. 네가 생각할 때까지 기다릴 (진행중)   38s │  │
│   │                                 │   │  │   (✨ 자동 센터 스크롤 포커스 하이라이트)  │  │
│   │                                 │   │  │   (단어 클릭 시 14종 사전 모달 즉시 팝업) │  │
│   └─────────────────────────────────┘   │  │ 12. 이렇게 한단 말이에요.             44s │  │
│   0:33 / 6:49               [🔊] [⛶]   │  │ 13. 지금 저 멀리서 들어오는...         45s │  │
│                                         │  └───────────────────────────────────────────┘  │
├─────────────────────────────────────────┴─────────────────────────────────────────────────┤
│  0:58 ═══════════════════════●══════════════════════════════════════════════════ 6:49     │
│  [0.75x] [1.0x] [1.25x]               [⏪ 5s]   [ ⏸ ]   [5s ⏩]              [🔁 구간반복]  │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

* **실시간 자동 센터 스크롤 (Auto-Scroll Centering)**: 재생 중인 문장이 보라색 그라데이션으로 강조되며 대본 스크롤 영역의 정중앙에 부드럽게 유지됩니다.
* **단어별 원클릭 사전 연동**: 대본 내 모든 단어에 마우스 호버 시 하이라이트되며, 클릭 시 14종 사전 모달이 즉시 열립니다.
* **타임스탬프 원클릭 점프**: 번호나 초(`33s`)를 클릭하면 해당 영상 구간으로 즉시 이동합니다.

## 🧠 5. IB 심층 탐구 & 소크라테스 실시간 티키타카 대화 시스템

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  🧠 IB 심층 탐구 & 소크라테스 3단계 산파관                                🔑 Gemini 연동됨 │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  🌟 1. 전체 내용 핵심 브리핑 (Lesson Overview & Storyline)                [🔄 브리핑 새로고침] │
│   ┌──────────────────────────────────────────────────────────────────────────────────┐ │
│   │ 📖 전체 줄거리 & 상황 맥락 요약 (2~3문장)                                         │ │
│   │ 🎯 핵심 메시지: 이 레슨이 전하고자 하는 가장 중요한 가치 & 원리                     │ │
│   │ 💡 Point 1, Point 2, Point 3 카드 (핵심 학습 포인트)                              │ │
│   └──────────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                        │
│  🏛️ 2. 3단계 점진적 IB 질문 & 3단계 꼬리물기 산파관 (Factual ➔ Conceptual ➔ Debatable)     │
│   • 📌 1단계 Factual (사실적 질문): 본문 내용 기반 사실 확인 질문                      │
│   • 💡 2단계 Conceptual (개념적 질문): 원리와 핵심 개념 탐구 질문                      │
│   • ⚖️ 3단계 Debatable (심층 토론 질문): 상식을 뒤집는 심층 토론 질문                  │
│   ┌──────────────────────────────────────────────────────────────────────────────────┐ │
│   │ [학생 답변 작성] ➔ [✨ AI 코칭 & 3단계 산파 질문 받기]                              │ │
│   │  ├─ 🌱 학생 생각 적극 칭찬 & 💡 따뜻한 콩글리시 코칭 팁                             │ │
│   │  ├─ 🎯 Polished English (원어민 교정 영작문) & 🏆 Advanced IB 에세이 모델         │ │
│   │  └─ 🏛️ 소크라테스(산파) / 🧠 파인만(비유) / ⚡ SCAMPER(발상전환) 3단계 꼬리물기 질문 │ │
│   └──────────────────────────────────────────────────────────────────────────────────┘ │
│                                                                                        │
│  💬 3. AI 소크라테스 실시간 티키타카 대화방 (Live Multi-turn Socratic Chat Room) ● 실시간    │
│   ┌──────────────────────────────────────────────────────────────────────────────────┐ │
│   │ 👤 학생: "왜 영어를 이미지로 연상하며 말해야 하나요?"                             │ │
│   │ 🤖 AI 코치: "훌륭한 질문입니다! 이미지는 한국어 번역 과정을 거치지 않기 때문입니다."  │ │
│   │    ✨ Polished English: "Visual imagery allows direct thought formulation..."    │ │
│   │    👉 티키타카 꼬리물기: "그렇다면 추상적인 감정 단어는 어떻게 이미지화할 수 있을까요?"│ │
│   └──────────────────────────────────────────────────────────────────────────────────┘ │
│   [ 💬 나의 생각이나 질문을 입력하세요...                             ] [ 전송 🚀 ]     │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **🌟 전체 내용 핵심 브리핑**: 본문에 들어가기 전, 전체 줄거리 요약과 핵심 메시지, 3대 학습 포인트를 자동 제공하여 전체 맥락을 먼저 이해하도록 지원.
2. **🏛️ 3단계 점진적 IB 질문 자동 생성**: 교사가 질문을 입력하지 않아도 AI가 영상 대본을 분석해 3단계 질문을 즉시 구성.
3. **💬 AI 실시간 티키타카 대화방**: 학생이 질문이나 의견을 채팅창에 입력하면 AI가 실시간으로 공감하고 생각을 심화시키는 꼬리물기 대화를 무제한 전개.
